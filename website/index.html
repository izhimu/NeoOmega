NeoOmega

为 Chrome 与现代化 Chromium 浏览器打造的高性能、无技术债代理管理与规则分流扩展。作为 SwitchyOmega / ZeroOmega 的现代化重构接棒者，彻底告别 CoffeeScript、AngularJS 1.x 与 Grunt 的旧时代架构。

立即安装 了解功能
Features

旧神该有的功能，一个不少；旧时代的包袱，一个不留

TypeScript + WXT (Vite) + Vue 3 纯现代技术栈，代码量精简 80%，启动瞬时响应。

Manifest V3

原生 MV3 架构

彻底适配 Service Worker 休眠与按需唤醒生命周期，配置与状态由 chrome.storage.local 统一驱动。

Profiles

完备的情景模式

直接连接、系统代理、固定服务器（HTTP / HTTPS / SOCKS4 / SOCKS5）、PAC 脚本、虚情景模式指针别名。

Auto Switch

自动切换

域名通配符、URL 正则、CIDR IP 分段匹配，支持 GFWList / AutoProxy 在线规则列表。

Security

隐私加固

WebRTC IP 泄露防护策略、代理认证（webRequest.onAuthRequired）与错误监控，流量走向一目了然。

Diagnostics

网络诊断

内置连通性与泄露检测，实时查看当前生效代理与出口 IP，排障不再靠猜。

Migration

备份与迁移

配置一键导出 / 导入，支持从 SwitchyOmega / ZeroOmega 备份文件直接迁移，换机零成本。

一键安装
