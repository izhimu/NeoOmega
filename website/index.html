Features

旧神该有的功能一个不少，旧时代的包袱一个不留

TypeScript + WXT (Vite) + Vue 3 纯现代技术栈，代码量精简 80%，随浏览器启动瞬时响应。

Manifest V3

原生 MV3 架构

彻底适配 Service Worker 休眠与按需唤醒生命周期，配置与状态由 chrome.storage.local 统一驱动。

Profiles

完备的情景模式

直接连接、系统代理、固定服务器（HTTP / HTTPS / SOCKS4 / SOCKS5）、PAC 脚本与虚情景模式指针别名。

Auto Switch

智能自动切换

域名通配符、URL 正则、CIDR IP 分段匹配，支持 GFWList / AutoProxy 在线规则列表自动更新与缓存。

Security

隐私加固与认证

原生 WebRTC IP 泄露防护策略、代理认证（webRequest.onAuthRequired）与错误拦截，流量走向尽在掌控。

Diagnostics

网络诊断中心

内置连通性测试、出口 IP 检测与延迟测速，直观排障，彻底告别盲猜节点状态。

Migration

无痛迁移与备份

配置一键导出与导入，支持从 SwitchyOmega / ZeroOmega 备份文件直接迁移，老用户零换机成本。

Screenshots

眼见为实

现代化设计语言、完整深色模式适配与符合直觉的操作逻辑。

Install

一键安装体验
