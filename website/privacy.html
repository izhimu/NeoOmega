Privacy Policy / 隐私权政策

最后更新日期 / Last updated: 2026-10-04

1. 核心承诺 / Core Privacy Promise

NeoOmega 是开源、免翻新旧技术栈的现代化 Chrome 代理管理扩展。我们尊重您的隐私：我们不收集、不存储、不出售任何个人数据或浏览记录。

NeoOmega is an open-source browser extension. We do not collect, transmit, sell, or store your personal data, web activity, or browsing history.

2. 我们不收集的数据 / What We Do NOT Collect

  • 个人身份信息：不收集姓名、电子邮箱、手机号等任何个人信息。
  • 浏览数据与网络流量：不监控、不记录、不上传您的访问网址、搜索记录或任何网页内容。
  • 分析与追踪埋点：不集成任何第三方统计分析平台（无 Google Analytics、无埋点 SDK）。
  • 代理服务器认证凭据：用户填写的代理账号与密码仅加密/存放在本地设备，绝不外传。

3. 本地存储机制 / Local Storage

  • 纯本地存储：所有情景模式、代理分流规则、白名单均保存在浏览器本地提供的 chrome.storage.local 隔离沙箱中。
  • 可选 Chrome 同步：若用户主动勾选“云端同步”，数据将通过 Google 官方加密的 chrome.storage.sync 通道在用户自己的登录设备间流转，NeoOmega 团队无法访问。

4. 扩展触发的网络连接 / Network Requests

扩展程序发起的网络请求仅限于以下用户直接配置的动作：

  • 规则订阅更新：按用户设定拉取用户指定的远程 PAC 文件或 GFWList 纯文本规则。
  • 网络防泄露诊断：当用户在网络设置页手动点击“开始检测”时，直接向公共 IP 查询服务查询当前出口 IP、WebRTC 候选状态与 DNS，诊断结果仅渲染在本地页面上，不留存、不上报。

5. 敏感权限用途声明 / Permissions Justification

  • proxy：配置 Chrome 代理转发规则。
  • storage：在本地保存用户的情景模式与偏好设置。
  • alarms：用于定时更新用户订阅的在线规则列表。
  • webRequest & webRequestAuthProvider：处理代理服务器密码认证，并捕获连接错误以建议分流规则。
  • sidePanel：提供浏览器常驻侧边栏调试与网络诊断界面。
  • scripting：在沙箱内检测 WebRTC 候选地址以防止真实 IP 泄露。
  • privacy：配置 Chrome WebRTC 防泄露安全策略。
  • <all_urls>：处理跨站代理认证握手。

6. 开源与监督 / Open Source Verification

NeoOmega 源代码完全开放，用户可随时在代码仓库审查上述隐私策略的真实性与合规性。
